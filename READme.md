This repository contains a complete **Brazilian Portuguese (PT-BR)** translation of Mark Twain's classic short story, *"Eve's Diary"*. 

In addition to the translation, this project provides a **Print-Ready HTML template**. The HTML/CSS has been meticulously crafted to emulate the physical pages of a book, complete with classic typography, margins, and page numbering, making it incredibly easy to export as a perfectly formatted PDF.

## ✨ Features

- **Full PT-BR Translation:** The complete text translated into natural and engaging Brazilian Portuguese.
- **Book-like Layout:** Custom CSS that visually simulates an A4/Letter printed book page right in your browser.
- **Print-to-PDF Ready:** Specifically designed with `@media print` rules to ensure that when you save it as a PDF, it breaks pages correctly, removes backgrounds, and looks like a real digital book.
- **Zero Dependencies:** Pure, vanilla HTML and CSS. No frameworks, no build tools required.

## 🚀 How to Use & Generate the PDF

You don't need any special software to read or generate the PDF. 

### Method 1: Using your Browser (Easiest)
1. Clone this repository or download the `DiarioDeEva.html` file.
2. Double-click the file to open it in your favorite web browser (Chrome, Edge, Firefox, Safari).
3. Press `Ctrl + P` (or `Cmd + P` on Mac) to open the print dialog.
4. Set the destination to **"Save as PDF"**.
5. Ensure the margins are set to "Default" or "None" and background graphics are unchecked for a cleaner look.
6. Click **Save**!

### Method 2: Using VS Code
1. Open the project folder in **Visual Studio Code**.
2. Open `DiarioDeEva.html`.
3. If you have the **Live Server** extension installed, right-click the code and select *Open with Live Server*.
4. Once it opens in your browser, follow steps 3 to 6 from Method 1.
5. *(Optional)* You can also use VS Code extensions like *HTML to PDF* to convert it directly inside the editor.

## 📚 About the Original Work

*"Eve's Diary"* is a comic short story by the American author **Mark Twain** (Samuel Clemens). It was first published in 1905 and is written as a diary kept by the first woman, Eve, documenting her experiences in the Garden of Eden and her evolving relationship with Adam. It is a companion piece to his earlier work, *"Extracts from Adam's Diary"*.
